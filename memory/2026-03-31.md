### Key Fixes That Made It Work

**1. Holonomic Heading Fix (CRITICAL)**
```python
# True heading = world displacement direction - body velocity direction
world_movement_angle = arctan2(dy, dx)  # direction robot actually moved
local_velocity_angle = arctan2(vy, vx)   # body-frame velocity angle
headings_gt = (world_movement_angle - local_velocity_angle) % 2π
```
For holonomic robots, heading ≠ direction of motion. The difference matters.

**2. Ring heading uses circular statistics**
```python
theta = arctan2(sum(sin·p), sum(cos·p)) % 2π  # handles 0°/360° boundary
```

**3. Body-frame to Global-frame velocity rotation**
```python
theta = ring_readout(self._r_ring)  # current heading
V_map_x = vx * cos(θ) - vy * sin(θ)  # global x velocity
V_map_y = vx * sin(θ) + vy * cos(θ)  # global y velocity
```
