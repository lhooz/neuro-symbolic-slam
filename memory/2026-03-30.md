## SNN-SLAM Twin: Major Progress!

### Current Architecture: Asymmetric Weight Current Injection
After many iterations, we converged on using asymmetric weight current injection (not direct shift) with:
- **Pure ReLU experiment** proved that without ceiling clamp, bumps grow too tall and create "energy wells" that cause grid-pinning
- **Stable clamps** (clip 0,1) work better - provide enough derivative for shift without pinning

### Key Fixes Applied (Tonight)
1. **Einsum transpose bug**: `einsum('nm,bn->bm', W, r)` was computing W^T @ r instead of W @ r. Fixed to `einsum('ij,bj->bi', W, r)`
2. **Meshgrid axis swap**: Changed `indexing='ij'` to `indexing='xy'` in build_2d_cann_weights, cann_readout, sensory_correction_xy, initialize_from_gt
3. **Ring direction**: With `diff = n - i`, the negation `I_vel_ring = -VEL_GAIN_TH * ...` gives correct direction
4. **Stable clamps restored**: `self._u_ring = clip(u_ring_new, 0, 1.0)`, `self._r_ring = self._u_ring`
