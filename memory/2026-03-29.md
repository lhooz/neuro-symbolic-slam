## SNN SLAM Digital Twin — Key Learnings

### Architecture Decisions (Permanent)

**The SNN uses two attractors:**
1. **2D CANN** (Continuous Attractor Neural Network) — 32×32 neurons for position
2. **1D Ring Attractor** — 64 neurons for heading

**Critical insight from today: These spiking attractors fundamentally fight velocity coupling.**

A continuous attractor's bump is a stable equilibrium of the Mexican Hat. To shift it via velocity current:
- Weak coupling → bump doesn't move (stuck at equilibrium)
- Strong coupling → bump jumps in discrete metastable chunks

This is a dynamical systems constraint, not a tuning problem.

### Area Balance Parameters

**2D CANN:**
- A_EXC=1.0, A_INH=0.20
- SIGMA_EXC=1.5, SIGMA_INH=2.5
- Area ratio ≈ 0.41, Self-connection ≈ 0.80, Row-sum ≈ +1.75
- These give stable, localized bump

**1D Ring:**
- A_EXC=1.0, A_INH=0.20
- SIGMA_EXC=2.0, SIGMA_INH=6.0
- Self-connection = 0.80
- CRITICAL: sigma_inh=6.0 creates SHALLOW inhibition → bump saturates to one-hot
- sigma_inh=2.5 creates STEEPER inhibition → bump more distributed, omega can shift it
- But steep inhibition → bump clips to one-hot → omega CAN'T shift it (catch-22!)

### Velocity Normalization Bug (Critical!)

**vx, vy labels were normalized by VX_RANGE[1]=0.8 and VY_RANGE[1]=0.3 but NEVER un-normalized in the SNN forward pass!**
- SNN received vx≈0.01 instead of vx≈0.4 m/s
- DR was getting tiny velocities → ratio 0.38 instead of 1.02
- **Fix:** Multiply kin inputs by velocity range:
  ```python
  kin = np.stack([
      np.tile(labels[:, 0:1] * np.abs(VX_RANGE[1]), (1, T)),
      np.tile(labels[:, 1:2] * np.abs(VY_RANGE[1]), (1, T)),
      np.tile(labels[:, 2:3] * np.abs(OMEGA_RANGE[1]), (1, T)),
  ], axis=2)
  ```

## Ring Attractor — Critical Bug Found!

### Root Cause: All-Positive Ring Weights
The 1D ring with A_exc=1.0, A_inh=0.20 has W_ring.min = +0.117 to +0.269 (ALWAYS POSITIVE!)
regardless of sigma_inh (tried 6.0, 4.0, 3.0, 2.0, 1.5, 0.75).

Why: With 64 neurons, one step = 5.62°. For W_ring.min < 0:
  A_inh × exp(-π²/(2×σ_inh²)) > A_exc × exp(-π²/(2×2²))
  With A_exc=1.0, A_inh=0.20: Need σ_inh ≈ 0.36 neurons = 2.0° (unphysically tight!)
  With σ_inh=0.75 neurons: W_ring.min = +0.269 still positive.

### The Explosion
With W_ring.min > 0, ANY subthreshold initialization (r=0.1) → ring SATURATES in 1 step:
- W_ring @ r ≈ 0.15 × 64 × 0.5 ≈ 4.9 (huge positive feedback!)
- u_new ≈ 3.3 → way above LIF threshold (v_th=1.0)
- r = 1.0 everywhere (uniform saturation)
- Velocity input has NO EFFECT on uniformly saturated ring
- The "heading" (center of mass) becomes arbitrary noise

### Verified with Isolated Python Test
- With sigma_inh=6.0: W_ring.min=+0.117, ring saturates in 1 step
- With sigma_inh=1.5: W_ring.min=+0.269, ring saturates in 1 step
- With sigma_inh=0.75: W_ring.min=+0.269 (barely changes!)
- CANN: Same issue? CANN has A_exc=1.0, A_inh=0.20, sigma_inh=2.5 pixels
  - In 2D, neuron spacing = ROOM_W/CANN_SIZE = 5m/32 = 0.156m
  - σ_inh=2.5 pixels = 0.391m → inhibition span = 2×0.391/5m = 15.6% of room
  - Similar issue: W_cann.min = A_exc × exp(-d²/(2σ_exc²)) - A_inh × exp(-d²/(2σ_inh²))
  - At far field (2.5m): ~0.291 - 0.20×0.778 = 0.291 - 0.156 = +0.135 (positive!)
