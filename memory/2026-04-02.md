### Critical Diagnosis: TWO SEPARATE PROBLEMS

**Problem 1: SOTA Gates Never Fire (conf=0.000 always)**
- W_fused_to_place randomly initialized — no associations learned yet
- SPARSITY/MATCH/ANTI-ALIASING gates correctly block blank memory corrections
- Ghost bumps are 0.0 at all timesteps — system runs open-loop
- At t=0: memory is BLANK, VisionSTDP features are novel, no match exists

**Problem 2: SNN Pose Diverges Even Without Corrections (3.88m vs 0.04m OL!)**
- With corrections explicitly zeroed: SNN still gets 3.88m error vs 0.04m simple IMU
- Ring Attractor heading actively diverging: 33.7° → 3.2° over 300 steps
- Mexican Hat + Ring recurrent dynamics amplifying IMU discretization errors
- This is a PoseCANN heading dynamics problem, NOT a loop closure problem

### Root Cause: Heading Initialization Mismatch
- `labels` format: (B, 4) — [vx_n, vy_n, omega_n, clearance_n] — constant per trajectory!
- GT positions: (B, T, 2) — each trajectory has unique movement
- Omega is CONSTANT per trajectory (e.g., batch 0: 10.9°/s, batch 1: -2.3°/s)
- Heading initialized at 0° but GT headings are ~33-50° range
- The SNN is being fed wrong omega values (too small, wrong sign for some batches)
